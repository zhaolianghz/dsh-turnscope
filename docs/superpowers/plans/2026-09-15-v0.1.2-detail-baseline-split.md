# V0.1.2 — Detail-List Baseline Split

Implementation plan for `docs/superpowers/specs/2026-09-15-v0.1.2-detail-baseline-split.md`.

Three bite-sized tasks.

## Task 1 — Group the change list

**File**: `src/client/TurnDetail.tsx`

- Replace the single `detail.changes.map(change => (<Change ... />))` block
  (around line 144) with a grouped renderer:
  - `const agentChanges = detail.changes.filter(c => !c.baseline)`
  - `const baselineChanges = detail.changes.filter(c => c.baseline)`
- When `baselineChanges.length === 0`: keep the current single `<ul>` (no
  behaviour change for clean turns).
- Else: render two lists separated by a labelled divider reading
  `本轮开始时已脏 (N)`.
- Per-row `本轮开始时已脏` badge stays; it is the per-row confirmation of
  what the divider already says in bulk.

**Verify**: `pnpm typecheck` clean.

## Task 2 — Tests for the split
